## ✦ Sobre o Projeto

Este projeto é o **portfólio profissional e laboratório interativo de engenharia** de **Henrique Monteiro Cardoso**, projetado sob a chancela de padrões corporativos do ecossistema `@agente-core` e governança de software de `C:\Segundo Cérebro`.

O sistema combina suporte completo a **internacionalização nativa (i18n)**, um **banco de dados reativo serverless (Convex)**, **simuladores funcionais no Interactive Lab** e um **assistente inteligente com streaming (Gemini AI)** alimentado com o histórico profissional e técnico factual de Henrique.

O desenvolvimento foi integralmente guiado pelos princípios de **Clean Architecture**, **Dark Mode Tri-Layer**, **performance extrema (Core Web Vitals LCP < 1.2s)** e **type-safety estrita de ponta a ponta**.

---

## ✦ O Diferencial Estratégico: Negócios + Engenharia de Software

O autor une duas fortalezas raras no ecossistema de desenvolvimento:
1. **Domínio Operacional Corporativo & Negócios:** Vivência prática com sistemas de ERP e CRM corporativos (**Bitrix**, **DKSoft**, **Sponte**, **RELATE**), controle estatístico de indicadores (**KPIs**), auditorias internas rigorosas de conformidade e padronização de processos com treinamento contínuo de equipes (atuações na **CCBEU** e na multinacional **ASSA ABLOY Group**).
2. **Engenharia de Software de Vanguarda & IA:** Modelagem de sistemas escaláveis em monorepos (**Turborepo**, **PNPM Workspaces**), **Clean Architecture** e isolamento puro de domínio, contratos type-safe com **TypeScript** e **Zod**, UI/UX de prestígio com **Tailwind CSS v4**, **Framer Motion** e **Three.js**, além de orquestração de **Agentes de IA Constitucionais** com protocolos de mitigação de alucinação (**FLARE** e **COVE**).

---

## ✦ Principais Recursos e Diferenciais

* **Internacionalização Dinâmica (i18n):** Roteamento localizado com alternância instantânea entre Português (`/pt`) e Inglês (`/en`), com detecção automática do idioma e sincronização via dicionários tipados.
* **Sincronização Reativa em Tempo Real (Convex BaaS):** Banco de dados serverless reativo. Atualizações em projetos ou submissão de mensagens no formulário de contato são sincronizadas instantaneamente sem recarregar a página.
* **Laboratório Interativo (`/labs`):** Módulo prático com simulações matemáticas interativas:
  * **Simulador ROI Solar (EcoVolt Lite):** Cálculo de geração fotovoltaica, economia mensal estimada, payback de investimento e projeção acumulada em 5 anos com gráficos Recharts.
  * **Calculadora ESG Carbon (Safe Finance Lite):** Estimativa mensal da pegada de carbono individual (eletricidade, transporte e hábitos de consumo) com benchmarking contra médias nacionais.
* **Assistente IA Integrado (Gemini AI Streaming):** Chatbot conversacional com streaming contínuo em tempo real conectado à API do Google Gemini, configurado com instruções sistêmicas estritas para responder sobre carreira, projetos e competências sem alucinações.
* **Design Engineering Premium & Dark Mode Tri-Layer:** Interface construída sobre a grade técnica de 8px e paleta escura tripla (Base `#0D0D0D`, Painéis `#1A1A1A`, Menus/Gavetas `#2D2D2D`), aceleração por GPU (`transform: translate3d(0, 0, 0)`) e física de mola via Framer Motion.
* **Validação de Formulários & Clean Architecture:** Contratos estritos de dados com esquemas Zod (`LeadEntity`, `ProjectEntity`), integrados ao React Hook Form com tipagem estrita de ponta a ponta.
* **Painel Administrativo Autenticado:** Área administrativa sob `/admin` protegida por autenticação segura via `@convex-dev/auth`, permitindo a gestão em tempo real de projetos e mensagens recebidas.

## ✦ Stack Tecnológica

### Frontend & Experiência Visual
- **React 19 & Next.js 16 (App Router):** Server Components híbridos e renderização de alto desempenho.
- **TypeScript:** Tipagem estática rigorosa sem uso de `any`.
- **Tailwind CSS v4:** Estilização utility-first de alta performance com temas nativos `@theme`.
- **Framer Motion:** Animações interativas físicas baseadas em molas (spring physics).
- **Three.js & React Three Fiber (R3F):** Gráficos 3D imersivos em canvas desacoplado.
- **Lucide Icons:** Iconografia técnica, semântica e acessível.

### Backend, Dados & Inteligência
- **Convex BaaS:** Banco de dados serverless reativo com sincronização em milissegundos e queries tipadas.
- **Google Gemini API:** Modelo LLM de última geração para assistência virtual conversacional com streaming.
- **Zod:** Validação estrita de esquemas em runtime, garantindo a integridade da camada de domínio.
- **@convex-dev/auth:** Autenticação serverless integrada para proteção do painel administrativo.

### Governança & Qualidade
- **Padrões @agente-core & C:\Segundo Cérebro:** Conformidade estrita de Clean Architecture, isolamento de domínio e zero secrets.
- **Playwright:** Testes automatizados de ponta a ponta (E2E) para validação de fluxos críticos de UI.
- **Lighthouse CI:** Monitoramento contínuo de métricas Core Web Vitals (LCP, INP, CLS) e acessibilidade WCAG.

## ✦ Instalação e Execução Local

### 1. Clonar o Repositório
```bash
git clone https://github.com/HenriqueMC17/portfolio-profissional.git
```

### 2. Instalar Dependências
```bash
npm install
```

### 3. Configurar Variáveis de Ambiente
Crie um arquivo `.env.local` na raiz do projeto:
```env
CONVEX_DEPLOYMENT=anonymous:anonymous-portfolio-profissional
NEXT_PUBLIC_CONVEX_URL=http://127.0.0.1:3210
NEXT_PUBLIC_CONVEX_SITE_URL=http://127.0.0.1:3211
GOOGLE_GENERATIVE_AI_API_KEY=sua_chave_gemini_aqui
```

### 4. Executar em Modo de Desenvolvimento
```bash
npm run dev:full
```

### 5. Popular o Banco de Dados (Seeding)
Acesse a rota administrativa `/pt/admin` e clique em **"Popular Banco (Mock Data)"** para carregar os projetos factuais (Safe Finance, EcoVolt, AutoMind AI) via `convex/seed.ts`.
